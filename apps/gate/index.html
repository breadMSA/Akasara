Gate

An ASE-0.1 signal source and the consent gate in front of it. The phone's own IMU stands in for a body-signal wearable: it produces real T1 feature frames in a pinned feature space, and nothing leaves this device unless a grant you wrote says it may. Default is deny. No account, no network, no server.

Runs the production T1 transform over ase.selftest.v1 and compares it to the vector the capability descriptor publishes.     Live stream (ASE §10.3 loopback)
    not connected

    Streaming is egress like any other: it runs under the same grant, obeys the same redaction, spends the same frame allowance, and stops by itself the moment the grant is revoked, expires, or runs out. Run node bridge.mjs alongside this page; while it is connected the capability descriptor declares a real local transport and R-7.1 passes.
